# Deepak Prasad Verma — Official Developer Portfolio (`DPV.dev`)

A modern, high-impact developer portfolio website built for **Deepak Prasad Verma** (`@deepakprasadverma`), Full-Stack MERN Developer & B.Tech Information Technology Student at **UCET Hazaribagh** (Diploma alumnus from **Government Polytechnic, Dumka**).

## ✨ Key Features
- **Cyber-Executive Glassmorphic UI** with Dark & Light Theme Switcher
- **Interactive Developer Terminal (`dpv-shell v2.6`)** — supports `help`, `about`, `skills`, `projects`, `education`, `audit`, `contact`, `bawal`, and `clear` (`Ctrl+K` shortcut)
- **Live GitHub API Sync** — automatically fetches live repository & follower counts from `api.github.com/users/deepakprasadverma`
- **Production Project Showcase & Architecture Inspector Modal**:
  - **OSHN BLRREALTOR** (`https://oshn-blr-realtor.vercel.app`) — React 19 + Tailwind v4 + Node.js + Express 5 + MongoDB
  - **Verma Brothers Fitness** (`https://verma-brothers-fitness.vercel.app`) — AI Workout Coach & Gym Web Platform
  - **Hybrid GPS & IP Geolocation Tracker** — Python + Folium GIS + PySerial + PyNMEA2
  - **Bawal Mode** — Interactive HTML5 Canvas Matrix & Particle FX Engine (with live fireworks tribute button!)
- **Personalized LinkedIn & GitHub Profile Audit Hub** — includes interactive score tracker (`78/100 → 100/100`) and 1-click copyable LinkedIn Headline & About Summary
- **Built-in ATS-Ready Printable Resume / CV Modal** — 1-click PDF print stylesheet

## 🚀 Quick Start
Open `index.html` directly in any browser, or run a local server:
```bash
npx serve .
```
